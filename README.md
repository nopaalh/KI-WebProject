Portal Pasien memakai Svelte dan TypeScript untuk frontend, serta Go/Gin dan PostgreSQL untuk backend. Login menggunakan cookie HttpOnly; identitas dan peran dibaca dari `/api/users/me`. Pendaftaran publik membuat akun pasien, sedangkan akun dokter disediakan rumah sakit. Frontend sudah memiliki portal pasien dan portal dokter yang terhubung ke backend; halaman rekam medis masih memakai data contoh.

Vite meneruskan `/api` ke backend lokal di port 8080. Pemeriksaan tipe dan build tersedia lewat `npm run check` dan `npm run build`. `npm run check:api` menguji API lokal yang sedang berjalan dan membuat satu akun sintetis. Kontrak backend dijelaskan di [API](docs/API.md).
